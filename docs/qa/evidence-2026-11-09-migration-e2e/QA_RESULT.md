## 二、过程记录（时间线，设备时钟略有偏差）

1. 旧机「开始迁移分享」→ 清单 102 文件 / 444.3 MB，显示 6 位数字码与端口（本轮 223 913 / 44897）。
2. 新机「自动搜索旧手机」→ 找到 1 台；「连接 192.168.31.105（端口 44897）」。
3. 旧机弹「请求接收」→ 点「允许这台新手机接收」→ 校验「已允许新手机接收」。
4. 约 5 秒完成（Wi-Fi 5GHz，链路 1201 Mbps，44 万文件无需等；页面出现「接收与校验完成。」）。
5. 关 Wi-Fi、关移动数据、force-stop、重开；本地曲库可见，进入「鲨鱼舞郭富城版 → 查看原视频」，video 正常出帧。
6. 恢复 Wi-Fi/移动数据；旧机停止分享并显示「已停止旧手机分享。」；两台屏幕常亮设置恢复原值。

## 四、本轮修复/改动要点

- 配对码：160 位 32 字符 → **6 位数字**（`123 456` 分组），HKDF 输入为 SHA-256(码)，安全性靠「同网段 + 握手限速 + 5 次失败锁 60 秒 + 一次性 + 10 分钟有效期」。
- 同 Wi-Fi 自动发现：旧机 UDP 42872 应答（只回 TCP 端口 + 128 位一次性 token，不回数字码）；新机广播搜索；
  握手携带 token 后**必须旧机用户点「允许」**才完成确认；拒绝/超时会明确失败，不回落明文。
- 安全余项：F6 nonce 缓存改按会话存储、满则拒绝并随会话丢弃；F8 `handleConfirm` 复核 `codeExpiresAt` 已有、本轮补连接总量/单 IP 上限与 10s 头部超时；F7 文案改为「同一局域网（同一 Wi-Fi 或 Tailscale）」并如实说明。
- 迁移完成后广播 `dance-migration-applied`，设置页重算缓存统计（修掉「迁移完成但显示 0 个文件」的旧 UI 状态）。

## 五、未覆盖（不得当已通过）

- **同步保护（migration-sync-guard）未做真机核验**：仅单测覆盖，未验证迁移中旧机后台上传确被闸门挡住、队列未删。
- 主动 MITM / 真机抓包 / 断网续传（传输中断点续传）未单独实测。
- 视频索引不随迁移走，新机首次可能整份重算摘要（512MiB 级视频有卡顿风险）；旧版本孤儿 sidecar 无法回溯识别等既有残留仍有效。

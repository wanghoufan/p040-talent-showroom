# P040 地图抽屉信息层次整改｜定向 QA（2026-10-31）

范围：只改沉浸练歌「地图」抽屉（结构工作室）的呈现层次与 CSS，不改数据口径、不改正式库、不动手机、不出声、不跑全量回归、未打包、未改版本号。

## 用户反馈与改动

用户原话：「点进那个地图之后，里面他妈的信息乱七八糟的，不知道他妈的要干什么。」
对照 `docs/qa/evidence-2026-10-31-prototype-phone/07-map-first-screen.png`、`08-map-scrolled.png`：同一屏出现「地图」「曲目详情」「结构工作室」三个标题/控件、两个 ✕、无参考说明 + 参考文件说明 + 波形 + 段卡 + 5 个操作按钮混排，没有步骤。

本次按「选段 → 试听/循环 → 调整边界或类型 → 确认并保存」重排：

| 位置 | 改动 |
|---|---|
| 标题与关闭 | 抽屉只保留一个「歌曲分段」标题与一个 ✕；原「地图」「结构工作室」双标题、双关闭全部删除，嵌套的两层 `role=dialog` 合并为一层 |
| ① 选一段 | 段卡改横排可滑（原型同款），点一下即选中并跳到段首；首屏可见「N 段 · 参考候选（未保存）· N 段待核对」 |
| ② 试听这一段 | 选中段大标题 + 精确区间；「▶ 试听」从段首开始（暂停时自动开播）、「整段循环 / 停止循环」、「回到段首」 |
| ③ 调整边界和类型 | 波形拖动 → 0.1 秒微调 → 对齐歌词行 → 类型 → 重复关系 → 撤销 / 删除 |
| ④ 保存 | 保存栏常驻底部，只在点按钮时写入；改类型/关系仍是草稿，不自动落库 |
| 技术文案 | 「参考与导入（可选）」`<details>` 默认收起：本机参考目录、载入参考文件、身份五项核验、来源说明、参考/正式结构切换、放弃参考都在里面 |
| 无参考/空结构 | 只给一句可操作提示与「播放位置打点 / 在末尾新增一段」，不出现身份核验、摘要、文件格式等技术词 |

## 保留的功能（逐项有测试）

- 波形拖动改分界点：`moveBoundary` + SVG 指针事件原样保留（jsdom 无布局取不到宽度，拖动本身仍需真机/浏览器手势验证，未在本轮宣称通过）。
- 歌词锚：`分界对齐歌词行` → 35.2s 吸附到 35.0s（用例「歌词行定界」）。
- 撤销：微调后撤销回原值；删掉最后一段后同屏仍有可用的「撤销」并退回。
- 手动打点：空结构连点两次得到两段并保存（用例「BABE 真正空结构」）。
- 重复关系：确认前只说「待确认」，点「旋律同、换词」后标题变「已确认」，重开仍成立（3 个用例）。
- 正式/草稿切换：收进「参考与导入」，切回正式结构后段数回到 2，且不写库。
- 参考候选与争议：10 段候选、2 段「待核对」、「待标注」类型、虚线段卡都仍在首屏段卡里，未隐藏。
- 显式保存：只有「保存为人工结构」写库，落库全部 `source=manual`；参考候选保存前不动正式结构。

## 未覆盖 / 风险

## 真实限制（不得当作已通过）

1. **真实离线播放 BLOCKED**：`src/native/filesystem.ts` 的 `isOfflineSupported()` 只在原生平台为真；浏览器里只能验证「未准备好时不谎报」和就绪计算，无法验证文件落盘后的断网播放。需真机或 Capacitor 环境补测。
2. **静音验证**：所有 `<audio>` 在页面内被置为 `muted=true / volume=0`，只按 `currentTime`、`paused`、`ended` 判定播放行为，未做听感/音质验证。
3. **未做全量回归**：按指令只跑唱歌相关单测/组件测试与本次场景；`npm test`、`node --test tests/*.test.mjs` 全量未执行。
4. **并行文件**：`src/pages/PerformancePage.tsx` 与其测试由另一路并行修改，本轮只读、未改；首次 `tsc -b` 曾命中其增量缓存报错，`tsc -b --force` 与最终 `npm run build` 均通过。
5. **大文件/时延**：媒体取自五首 demo（每首 1–1.2 分钟），未覆盖长音频、超大 LRC、弱网抖动。
6. **测试工具**：本机无 Playwright/Puppeteer，用 Node 24 原生 WebSocket 直连 BrowserOS CDP；脚本在 `/tmp/p040-v21-qa-20261030/`，不属于项目交付物。

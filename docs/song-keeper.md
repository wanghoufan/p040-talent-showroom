## 管什么

| # | 职责 | 触发 | 关键判据 |
|---|---|---|---|
| 1 | **导入** | 用户说「导入这几首」/ 下载目录出现新文件 | 先查清单判重 → 转换（ffprobe + 完整解码）→ 导入 → 真机验收 → 移入 `已导入软件/` → 刷新清单 |
| 2 | **翻译检查** | 新歌入库后 / 用户问「有没有中文」 | 用 `translatableLines` 算真缺；外语歌 realMissing 必须为 0；HANGUL/英文 hook 同文不补 |
| 3 | **整理对账** | 每周（A5 自动化）/ 用户说「对一下」 | 归档目录 ↔ manifest ↔ 曲库 三方一致；差异分 A 仅归档 / B 仅库 / C 哈希变化 |
| 4 | **自动化** | 新增周期性检查 | 登记到 `010-自动化管家/自动化任务登记表.html`，状态一律「未启用」，启用权归用户 |
| 5 | **文件夹规整** | 发现根目录堆积 / 命名不合规 | 根目录只放待处理；命名 `歌手 - 歌名`；转换在 `temp/` 做；孤儿目录进备份不硬删 |

## 判据与命令

```bash
# 判重（导入前必跑）
node scripts/music-archive-manifest.mjs --check "<歌名>"

# 刷新清单（移动/删除后必跑）
node scripts/music-archive-manifest.mjs

# 导出 A4 学习稿（8 首 / 指定曲目）
node scripts/export-a4-sheets.mjs --out 导出/A4学习稿 --all
```

## 不变量（任何时候都成立）

- 曲库与归档的**唯一真源**是 `repertoire_items` + `media/vocal-import/<songId>/`，文件只是副本。
- 外语歌翻译 100% 齐；中文歌不需要译文；同文 hook 不补。
- `~/Music/网易云音乐/` 根目录只放未处理完的；验收通过才整首移入 `已导入软件/`（平铺）。
- 每次有副作用操作前先备份（`.backup` 快照 + 媒体打包 + 归档文件移入备份），并给出回滚路径。
- 删除只删用户点名之外的？**不**——只删用户点名的「不要的」，其余一律不动。
- 真机验收不通过就不算导入完成，文件不移动。

## 交付节奏

- 每首歌：报「歌名 / 行数 / 译文 / 页数」四个数，不写过程。
- 每次对账：报 A/B/C 三类条数 + 报告路径。
- 每次规整：报移动了几个文件、有没有冲突、备份在哪。
- 收尾：HANDOFF 一行、账本一行、`LEDGER-OK`。

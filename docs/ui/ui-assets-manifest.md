## Exact interaction hierarchy

- Bottom tabs: 曲库 / 今晚歌单 / 演出模式 / 我的。
- Library top scene filters: 全部 + 耍酷 / 性感 / 户外 / 转场；多选 AND。
- Left/state rail: 会跳 / 正在练 / 想学；单选。
- Header actions: search + plus. Plus opens “收录舞蹈”.
- Import sheet explains that collection creates reference video + source audio clip + song metadata + status/tags.
- Detail primary actions: 播放音乐 / 查看原视频.
- Performance mode: big transport controls; no edit/delete/reference video.

## Visual rules

- Masculine / street / technical, not cute.
- Electric blue is the only brand accent in chrome; no pink decorative accents.
- Covers are user media and may contain any color.
- The generated prototype contains illustrative cover art and potentially imperfect generated text. Never bundle or OCR it.
- All click/tap hit targets ≥48dp.

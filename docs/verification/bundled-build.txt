## 2. 交付态 WebView 源与 LAN 连通方案（本轮修复）

- 现象：bundled 包 WebView 源默认 `https://localhost`，向私有 LAN 明文 HTTP API（`http://192.168.31.43:8791`）发请求被 **mixed content 拦截**：
  fetch 报 `TypeError: Failed to fetch`；`<audio>` 报 `MEDIA_ELEMENT_ERROR: Format error`（同样媒质，blob 播放正常，证明编解码无问题）。
- 处置（`capacitor.config.ts`）：交付态设 `server.androidScheme: 'http'`（WebView 源改为 `http://localhost`）＋ `android.allowMixedContent: true`。
- 结果：真机 WebView `location.href == http://localhost/`；对 API 的 fetch 返回 200；`<audio>` 正常加载播放。

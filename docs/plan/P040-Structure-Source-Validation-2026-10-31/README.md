## 产品决策建议

1. 歌曲身份先比对：歌手、歌名、Live/Remix/翻唱、时长和本地文件 hash；严格拦截同名不同歌。
2. 外部资料仅供参照：当前既没有可授权的完整结构 API，也未获第三方内容再利用许可。不要集成未授权的自动抓取端点；可为用户提供站外查阅入口，或者手动输入少量结构类型序列。
3. 用户提供或获许可的结构标签 → 对照本地 LRC 的句子排序，建议段首时间；只出“候选地图”，不能自动覆盖已有数据。
4. 音频聚类只辅助发现重复和边界候选，不自动把相似段落判为“同旋律”，不自动识别 Rap。
5. 手机 V1.2 交互：曲库点歌直达沉浸练歌，地图抽屉内支持“参考结构”“当前播放打点”“歌词行定界”“波形拖动”“听/循环/改”；任何冲突需能一键选参考或保留人工。
6. 人工确认后才可保存为 source=manual；手工结构绝不被重扫替换。无来源的继续人工打点。
7. 伴奏提取/生成/人声分离仍暂停，现有 MP3 和 LRC 只读；保留中韩译文、句循环、Rap 可选跳过与四 Tab 全局导航（仅练唱页隐藏）。

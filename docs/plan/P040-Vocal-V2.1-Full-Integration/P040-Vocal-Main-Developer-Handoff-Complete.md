## 用户已确认且不可改的核心决定

1. **继承 P040 Android 页面外壳**：原顶部「舞蹈 / 吉他 / 唱歌」及「批量管理」「+」，原底部四 Tab：「曲库 / 今晚节目单 / 演出模式 / 我的」；唱歌详情也保留底部 Tab。曲库仍用**双列卡片**，非桌面单列和左右分栏。
2. 搜索下一共只有**两行标签**：第一行「状态」+「全部 / 想学 / 练习中 / 已学会」；第二行「语言」+「全部 / 中文 / 英文 / 韩文」。每组一整行，默认不折叠，不增加 Rap 比例筛选，也不要在歌卡显示 Rap 占比。
3. 点击一首歌，先清楚展示**主歌 A1/A2、副歌 B1/B2、重复关系及 Rap 位置**，可点段跳转；紧接歌词及点句定位；重复旋律但歌词不同仍需练。无真实分析结果必须标「待分析」，不能冒充 AI 自动成功。
4. 播放器按**手机 390dp**设计：固定在四 Tab 上方；进度条；重播、−5s、播放/暂停、+10s、单曲循环；跳 Rap 开关、合练一遍、练习设置、速度。设置可选进/退 5/10/15/30 秒；歌词可回退 2/4/自定义 N 句，自动循环该片段。合练从头播一遍、跳过所有 Rap、结束即停止。
5. 底部「我的」的主题、联网、离线缓存与同步沿用现状；练习 ⚙ 只做练唱相关设置，**不另造第二套全局设置模式**。
6. 五首原创歌曲各有**伴奏 MP3 + 合成导唱旋律 MP3**、配套 LRC（2 中文、2 英文、1 韩文；无 Rap、少 Rap、多 Rap），均带**手工预设示例结构**。合成导唱不是人声，原型「原唱」用于演示切轨，不能宣称真人演唱。不要把原创演示当商业歌曲，不要把预设结果当 AI 分析。
7. **KTV 式演出是必做范围**：沿用 P040 原来的「今晚节目单」与「演出模式」两个 Tab。唱歌曲目可同时关联原唱和伴奏两个独立 MP3；练唱有原唱时默认原唱，可切伴奏；**演出默认伴奏**，可现场一键切「伴奏 / 原唱」，保持当前位置和播放/暂停状态、歌词同步。切歌后重置伴奏、等待手动播放；演出不继承练唱跳 Rap/逐句循环。单轨、缺轨不得假切换，伴奏缺失不可偷偷用原唱充当伴奏。准备离线演出校验两条音轨及歌词、结构，仍允许舞蹈/吉他/唱歌混排、排序和切歌。

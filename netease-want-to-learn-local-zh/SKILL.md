# 网易云想学音乐导入

## 触发词

- 导入想学音乐〔用户〕

## 目的和范围

从用户本人网易云音乐的“想学”歌单，逐首下载并导入当前项目；只有成功并在用户指定手机上验证后，才把对应文件归档、把歌曲从“想学”转到“已导入软件”。已有曲目先去重，失败项原地保留，绝不批量扫整个人的音乐库。不做人声分离或生成伴奏。歌词已是中文时无需翻译；其他语言才使用项目现有翻译流程，并如实报告成功或失败，不编造译文。

## 准备

- 项目须有 Node.js 24、ffprobe/ffmpeg、SQLite 和现有 `server/vocal-import` 模块；先定位当前手机实际连接的服务、库与媒体目录，不把隔离库误认成生产库。不得打印配对码或密钥。
- 需要已登录的网易云音乐桌面客户端、用户指定的音乐下载目录和“想学”“已导入软件”两个歌单；目录由用户提供或在客户端设置中核实，不写死机器路径。目标目录同名冲突时停止，不覆盖。
- NCM 使用用户指定且已授权的本机转换器；转换时先选隔离输出目录、保留原始文件，勾选外嵌歌词。转换得到的音频若为 FLAC 等其他格式，先核实真实编码，再按用户需求转换，不以扩展名假装 MP3。
- 手机执行设备锁的 `status → resolve → adb -s`，只操作用户指定型号，结束后按项目设备纪律释放；不得在手机上选择导入文件，导入在电脑侧完成。

## 实施

1. 查看“想学”歌单并记录歌曲名、歌手；在网易云音乐中逐首下载，检查任务完成及下载文件真实落盘。客户端歌单下载按钮无反应时，可用歌曲右键「下载」，不要反复刷新或下载不属于该歌单的内容。
2. 原始下载目录只读：MP3/LRC 复制到项目 `.local/` 的每首独立暂存目录；NCM 在转换器中转换到隔离目录，输出不得覆盖其他文件。使用 ffprobe 核对真实编码/时长、ffmpeg 完整解码，保留原始 NCM。输出 LRC 即使存在也要与原始 LRC 比较；若内容或编码不一致，导入原始 LRC 的副本，确保时间轴不变。缺歌词、身份不一致或转换失败即停该首，保持原歌单和文件。
3. 先对隔离库、独立媒体目录运行本目录 `import-one.mjs` 验证；每个输入目录只放一首音频及对应 LRC。生产或用户正在使用的库先一致性备份，再按相同方式导入。脚本默认 dry-run，只预检；`--apply` 要求备份目录并仅导入原唱及歌词，不启动 worker。示例参数按环境替换：

   ```bash
   node <skill目录>/import-one.mjs --source-dir <单曲暂存目录> --db <目标数据库> --media <目标媒体目录>
   node <skill目录>/import-one.mjs --source-dir <单曲暂存目录> --db <目标数据库> --media <目标媒体目录> --backup-dir <项目备份目录> --apply
   ```

   脚本遇到同名同歌手直接跳过，不推断不同版本一定相同；需核对的扫描结果不写库。导入后回读曲目身份、音轨和歌词数量；备份与真实音频不得入 Git。
4. 在目标手机重新进入唱歌曲库触发刷新，确认歌曲名称、歌手、歌词与时长；播放并验证媒体状态确实推进、未静音且无错误，再暂停。无法远程听见扬声器时只报告播放状态，不声称人工听感通过。手机显示旧列表时先退出曲目再重进曲库刷新，不重复导入。
5. 成功后，将本次原始下载 NCM/MP3 和 LRC、以及转换后的 MP3 移到用户指定的“已导入软件”文件夹；移动前检查目标无同名文件，逐文件比较移动前后 SHA-256。保留项目暂存副本和数据库备份，禁止清理别人的文件。
6. 在网易云歌单里先将歌曲添加到“已导入软件”，打开目标歌单核实；再从“想学”移除同一首，最后回读两边。仅对实际验证通过的歌曲执行，不改其他歌；中断后先检查已完成状态，重跑不重复入库或重复归档。

## 本次实测和限制

2026-10-31 在 macOS 上以 NCM + LRC 实测一首：转换 MP3 完整解码通过，原始歌词 48 行，隔离库导入与重复跳过通过；手机端显示歌词、播放推进且无媒体错误；原始 NCM、歌词和 MP3 已归档，两边歌单已回读。人工扬声器听感未采集。此项是单首实测，不代表批量、Windows/Linux 或其他网易云版本已验证。翻译分支与直接 MP3 分支未在本次实跑；缺歌词、付费限制或身份冲突时如实记录并保留待处理。

## 安装、配置、调用

- 项目内：保留本目录及脚本，使用项目现有依赖；其他平台先验证客户端、转换器、Node、ffmpeg、ADB 和路径写法。
- 配置：用户提供下载目录、归档目录、目标服务库与媒体目录；任何凭据留在原安全存储，不写进 Skill、日志或 Git。
- 调用：`导入想学音乐`。将按歌单逐首执行并回报每首结果，失败项不移动。
